# Promemoria (Android / Samsung)

Aggiungi quanti promemoria vuoi, scegli l'orario: ogni giorno a quell'ora compare una notifica **a tutto schermo** (anche a telefono bloccato) con suono e vibrazione.
Dalla schermata puoi premere **FATTO** oppure **posticipare** di 5/10/30/60 minuti o di un numero a scelta. I dati restano solo sul telefono.

- Tocca **+** per creare un promemoria; tocca una riga per modificarla; interruttore per attivare/disattivare; tieni premuto per eliminare.
- Al primo avvio concedi: notifiche, "schermo intero" e (consigliato) "Mostra sopra altre app" per vedere la schermata piena anche a telefono in uso.
- Su Samsung: Impostazioni › App › Promemoria › Batteria › **Senza restrizioni**.

## Ottenere l'APK
GitHub › Actions › "Build APK" › ultimo run › artefatto `promemoria-apk` › installa `app-debug.apk` (consenti "installa da origini sconosciute").
Oppure in locale con Android Studio / `gradle assembleDebug`.
